# Грешна подредба

Написа „ghbdtn“ или „zdravej“, защото клавиатурата беше на английски? Маркирай текста и натисни **Ctrl + Alt + Space**. Програмата го поправя на място: „здравей“. Работи и обратно: „геввд“ → „hello“.

**Свали:** [последната версия](https://github.com/waitingboy-collab/layout-fixer/releases/latest/download/LayoutFixer-Setup.exe) · Windows 10/11, 64-bit, не изисква .NET и админ права.

## Как работи

- Маркираш текста и натискаш клавиша. Ако нищо не е маркирано, програмата поправя последната дума преди курсора.
- Сама познава посоката: латиница → кирилица или кирилица → латиница.
- След поправката превключва подредбата на правилната, за да продължиш да пишеш.
- Работи във всяка програма: Word, Outlook, браузъри, Viber, Teams.
- Живее като иконка „Б“ до часовника. Настройките са в менюто на иконката.

## Поддържани подредби

| В Windows | KLID | В менюто |
|---|---|---|
| Bulgarian | 00030402 | БДС |
| Bulgarian (Phonetic) | 00020402 | Фонетична |
| Bulgarian (Phonetic Traditional) | 00040402 | Фонетична традиционна |
| Bulgarian (Typewriter) | 00000402 | БДС |

По подразбиране програмата сама намира коя българска подредба имаш инсталирана. Таблиците са взети от официалните KLC файлове на Windows.

## Клавиш

`Ctrl + Alt + Space` по подразбиране. Може да избереш и `Pause` или `Ctrl + Shift + Space`. Последната комбинация в Word е „непрекъсваем интервал“, затова не е по подразбиране.

## Структура

```
src/LayoutFixer.Core     таблиците и преобразуването (без Windows зависимости)
src/LayoutFixer          програмата с иконката (WinForms)
tests/LayoutFixer.Tests  xUnit тестове
installer/               Inno Setup
```

## Тестове

```
dotnet test
```

Тестовете проверяват всяка подредба с реални думи, обратния превод на всеки клавиш, че таблиците нямат повтарящи се символи и че всички 30 букви са достъпни. GitHub Actions ги пуска при всеки push. Нова версия не излиза, ако някой тест падне.
